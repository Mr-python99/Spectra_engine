## 📦 Installation

### Kali Linux

```bash
apt update
apt install python3 python3-venv git -y
```

### Clone Repository

```bash
git clone https://github.com/Mr-python99/Spectra_engine.git

cd Spectra_engine
```

### Create Virtual Environment

```bash
python3 -m venv venv

source venv/bin/activate
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run

```bash
python3 spectra.py
```
